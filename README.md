# NodeFlix

Projeto de demonstração relacionado ao NodeFlix, que apresenta alguns dos meus animes, séries e filmes que fazem parte da minha vida ao longo do caminho.

![screenshot](/public/images/readme.png)

## Tecnologias Utilizadas 🚀

- Node.js 24
- TypeScript 5
- Express.js 4.18

## Instalação e Uso 🛠️

1. Clone o repositório:

git clone https://github.com/allecosta/nodeflix.git

2. Entre na diretorio do projeto:
   
cd nodeflix

3. Instale as dependências:

npm install

4. Inicie o servidor:
   
npm run start-dev (irá executar o nodemon)

5. Acesse a aplicação em: http://localhost:8081
